# מאגר תוצאות בחירות – IVR ימות המשיח

הפרויקט נמצא בתיקייה `election26/` כדי לא לשנות את מערכת עדכוני הבחירות הקיימת.

נתוני המקור כוללים 1,199 סיכומי יישובים ו-11,542 קלפיות. הנתונים עדיין דורשים אימות רשמי של שיוכם למערכת הבחירות המבוקשת. שמות המפלגות נשמרו לפי אותיות/סמלים כפי שהופיעו בקובצי המקור.

קובצי הנתונים נשמרים כ-GZIP מקודד Base64 כדי להישאר קבצי טקסט תקינים ב-GitHub; ה-API יפענח אותם בזמן טעינה.

הערה: ימות עדיין אחראית לקליטת המקשים הפיזית. שרת Vercel אינו יכול לקלוט DTMF ישירות.
